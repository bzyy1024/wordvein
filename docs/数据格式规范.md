# 数据交换格式规范 v1.0

> 用途：由需求方提供数据文件，开发方按此规范编写导入脚本。
> 格式：**JSONL（JSON Lines）** —— 每行一个完整 JSON 对象，便于增量追加、逐行校验、大文件流式读取。
> 编码：**UTF-8 无 BOM**；换行符 `\n`；文件名固定为 `morphemes.jsonl` 与 `words.jsonl`，放在仓库 `data/` 目录下。

---

## 总览

| 文件 | 内容 | 建议顺序 |
|---|---|---|
| `morphemes.jsonl` | 词素定义（词根 / 前缀 / 后缀 / 词干 / 组合形式） | **先导入** |
| `words.jsonl` | 单词、释义、例句，以及引用词素的拆解 | 后导入 |

导入脚本会自动生成第三层数据，你**不需要**手工提供：

- `word_morphemes`（根据 `words.jsonl` 的 `breakdown` 自动生成）
- `morpheme_relations` 中的 `variant` 关系（根据 `morphemes.jsonl` 的 `variants` 自动生成）
- `morphemes.word_count`（导入完成后回填）

---

## 一、`morphemes.jsonl`

每行描述**一个词素**。这是全站的核心资产。

### 字段表

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `form` | string | ✅ | 规范书写形式，作为唯一标识。**前缀后缀带连字符**：`pre-`、`-able`、`-tion`；词根不带：`dict`、`spect` |
| `type` | string | ✅ | `root` \| `prefix` \| `suffix` \| `stem` \| `combining` |
| `meaning_cn` | string | ✅ | 中文含义，如 `"说，讲，宣告"` |
| `meaning_en` | string | 建议 | 英文含义，如 `"to say, speak, declare"` |
| `origin_lang` | string | 建议 | 来源语言代码，见下方枚举 |
| `etymology` | string | 建议 | 词源说明，如 `"拉丁语 dicere（说），过去分词 dictus"` |
| `story` | string | 可选 | 助记故事 / 口诀，会展示在详情页 |
| `caution` | string | 可选 | 易混提示，如 `"注意与 -ible 的区别：-able 多接本土词"` |
| `variants` | string[] | 可选 | 变体形式数组，如 `["spec","spic"]`。脚本会自动建立双向 `variant` 关联 |
| `related` | string[] | 可选 | 语义相关的其他词素 `form`，建立 `related` 关联 |
| `opposites` | string[] | 可选 | 反义前缀，如 `pre-` 的 opposites 填 `["post-"]` |

> `slug` 无需提供，脚本由 `form` 自动生成（去掉连字符、转小写、空格转 `-`）。

### `origin_lang` 枚举

| 代码 | 含义 |
|---|---|
| `L` | 拉丁语 Latin |
| `G` | 希腊语 Greek |
| `OE` | 古英语 Old English |
| `OF` | 古法语 Old French |
| `F` | 法语 French |
| `PIE` | 原始印欧语 Proto-Indo-European |
| `ME` | 中古英语 Middle English |
| 其他 | 自填，前端会做兜底展示 |

### 示例

```jsonl
{"form":"dict","type":"root","meaning_cn":"说，讲，宣告","meaning_en":"to say, speak, declare","origin_lang":"L","etymology":"源自拉丁语 dicere（说），过去分词 dictus","story":"助记：dictation 听写，就是老师『说』你来写","variants":["dic","dit","dex"],"related":["log","loqu","nounc"]}
{"form":"spect","type":"root","meaning_cn":"看，观察","meaning_en":"to look, to see","origin_lang":"L","etymology":"源自拉丁语 specere（看）","variants":["spec","spic","spit"],"story":"spectator  spectator = spect(看) + -ator(人) → 观众"}
{"form":"pre-","type":"prefix","meaning_cn":"在…之前，预先","meaning_en":"before, in advance","origin_lang":"L","variants":["prae-"],"opposites":["post-"]}
{"form":"-able","type":"suffix","meaning_cn":"能够…的，值得…的","meaning_en":"capable of, worthy of","origin_lang":"L","caution":"本土词多加 -able（readable）；拉丁词根多用 -ible（visible）"}
{"form":"-tion","type":"suffix","meaning_cn":"表动作、过程、结果","meaning_en":"act, process, result","origin_lang":"L","variants":["-ion","-ation","-sion"]}
```

## 二、`words.jsonl`

每行描述**一个单词**，包含释义、例句与词素拆解引用。

### 字段表

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `word` | string | ✅ | 单词本身，小写形式，如 `"predictable"`。**大小写重复会被跳过并记入报告** |
| `phonetic` | string | 建议 | 音标，建议含斜杠：`"/prɪˈdɪktəbl/"` |
| `pos` | string[] | 可选 | 顶层词性列表，如 `["adj."]`（义项级词性以 `senses[].pos` 为准） |
| `freq_rank` | integer | 建议 | 词频排名，越小越常用。**强烈建议提供**——同族词默认按此排序，缺失会导致同族词列表顺序无意义 |
| `cefr` | string | 可选 | `A1` / `A2` / `B1` / `B2` / `C1` / `C2` |
| `difficulty` | integer | 可选 | 1~5，缺省 3 |
| `tags` | string[] | 可选 | 标签名，如 `["CET6","考研"]`。脚本会自动建 `tags` 行（`code` 取自身，`kind` 默认 `exam`） |
| `senses` | object[] | ✅ | 义项数组，见下表 |
| `breakdown` | object[] | 建议 | 拆解数组，见下表。**缺失则该词无拆解数据**，页面走 F8 兜底 |
| `gloss` | string | 建议 | **构词串讲**：一句话把各词素含义串成单词含义，这是本网站区别于普通词典的关键内容。如 `"预先(pre-) 说出(dict) 的(able) → 可预测的"` |

### `senses[]` 义项对象

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pos` | string | 可选 | `n.` / `v.` / `adj.` / `adv.` / `prep.` |
| `definition_cn` | string | ✅ | 中文释义（**唯一必填**） |
| `definition_en` | string | 可选 | 英文释义 |
| `example` | string | 可选 | 英文例句 |
| `example_cn` | string | 可选 | 例句译文 |
| `sort_no` | integer | 可选 | 排序号，缺省按数组顺序 |

### `breakdown[]` 拆解对象

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `form` | string | ✅ | 引用的词素规范形式，**必须与 `morphemes.jsonl` 中的 `form` 完全一致**（含连字符）。引用不存在的 form 会被记录到导入报告中 |
| `position` | string | 可选 | `prefix` / `root` / `suffix` / `combining`。缺省时由 `type` 推断 |
| `order_no` | integer | 可选 | 拼接顺序，缺省按数组顺序 |
| `note` | string | 可选 | **该词素在本词中的具体含义/作用**（区别于词素通用含义）。如 `dict` 在 `contradict` 中 note 可写 `"反着说 → 反驳"` |

> 若某个词素只在此处出现而不在 `morphemes.jsonl` 里，脚本**不会自动创建**（避免脏数据），而是写进导入报告由你确认后再补 —— 保证词素表始终是经过审核的核心资产。

### 示例

```jsonl
{"word":"predict","phonetic":"/prɪˈdɪkt/","freq_rank":2841,"cefr":"B1","tags":["CET4","考研"],"pos":["v."],"gloss":"预先(pre-) 说出(dict) → 预言，预测","senses":[{"pos":"v.","definition_cn":"预言；预测；预报","definition_en":"to say that something will happen in the future","example":"No one can predict the outcome.","example_cn":"无人能预测结果。"}],"breakdown":[{"form":"pre-","note":"预先"},{"form":"dict","note":"说"}]}
{"word":"predictable","phonetic":"/prɪˈdɪktəbl/","freq_rank":6821,"cefr":"B2","tags":["CET6","考研"],"gloss":"预先(pre-)说出(dict)得出来(-able)的 → 可预测的","senses":[{"pos":"adj.","definition_cn":"可预测的；意料之中的","example":"The ending was predictable.","example_cn":"结局在意料之中。"},{"pos":"adj.","definition_cn":"（人）行为老套、可预料","example":"He's so predictable.","example_cn":"他这人做事毫无悬念。"}],"breakdown":[{"form":"pre-"},{"form":"dict"},{"form":"-able"}]}
{"word":"contradict","phonetic":"/ˌkɒntrəˈdɪkt/","freq_rank":5210,"cefr":"C1","gloss":"反着(contra-)说(dict) → 反驳，与…矛盾","senses":[{"pos":"v.","definition_cn":"反驳，否认；与…发生矛盾","example":"The two reports contradict each other.","example_cn":"两份报告相互矛盾。"}],"breakdown":[{"form":"contra-","note":"相反，对抗"},{"form":"dict","note":"说"}]}
{"word":"spectator","phonetic":"/spekˈteɪtə(r)/","freq_rank":7433,"cefr":"C1","gloss":"看(spect)的人(-ator) → 观众","senses":[{"pos":"n.","definition_cn":"（比赛等的）观众，旁观者","example":"Thousands of spectators filled the stadium.","example_cn":"成千上万的观众挤满了体育场。"}],"breakdown":[{"form":"spect","note":"看"},{"form":"-ator","note":"做…动作的人"}]}
{"word":"the","phonetic":"/ðə/","freq_rank":1,"senses":[{"pos":"art.","definition_cn":"这个，那个（定冠词）"}],"breakdown":[]}
```

> 注意最后一行：**允许 `breakdown` 为空数组**，表示该函数词/基础词无词根拆解数据，页面走兜底展示，不算错误。

## 三、导入脚本行为约定

```
pnpm run import -- --dir ./data [--dry-run] [--truncate]
```

| 行为 | 说明 |
|---|---|
| **幂等 upsert** | 重复执行不会产生重复数据；`words` 按 `lower(word)`、`morphemes` 按 `form` 做 upsert |
| **不自动建词素** | `breakdown` 引用了未定义的 form → 跳过该条拆解，写入报告，不中断整体导入 |
| **顺序无关** | 两文件可任意顺序导入；缺失的引用在每次导入结束时重新扫描补全（pending 队列） |
| **事务** | 每个文件的导入在单事务内完成，失败整体回滚；`--dry-run` 只出报告不写库 |
| **回填 word_count** | 导入完成后统一执行 `refresh_morpheme_word_count()` |
| **产出报告** | `data/import-report.md` |

### 导入报告内容（`data/import-report.md`）

```
✅ words 入库         : 4,820 条（新增 4,820 / 更新 0）
✅ morphemes 入库     : 312 条
✅ 拆解关系生成       : 11,204 条
✅ 变体关系生成       : 186 条
✅ 标签               : 8 个

⚠️  未定义词素引用     : 47 次，涉及 23 个单词
    - "contra-" 被引用 12 次  (contradict, contrary, contrast...)
    - "-ator"  被引用  9 次  (spectator, creator...)
    - "log"    被引用  6 次  ...
⚠️  无拆解数据单词     : 612 条（12.7%）
⚠️  缺 definition_cn  : 3 条

```

这份报告就是你的数据补齐清单：**优先补"引用次数最多"的未定义词素**，性价比最高。

## 四、最小验证集（建议先提供这个）

为了先跑通全流程、避免一次性返工，建议首批只给：

- `morphemes.jsonl`：**30~50 个**高频词素（10 个常用前缀 + 10 个常用后缀 + 15~20 个核心词根）
- `words.jsonl`：**100~300 个**单词，覆盖这些词素，且至少包含 2~3 个「同词根 5 词以上」的词族（如 `spect` 族、`dict` 族）用于验证同族词页面效果

跑通后我们确认页面表现与字段取舍，你再放量给全量数据。

## 五、字段速查（填数据时对照）

```
word          → 小写单词
phonetic      → "/prɪˈdɪkt/"
freq_rank     → 整数，越小越常用（决定同族词排序，务必提供）
cefr          → A1 A2 B1 B2 C1 C2
tags          → ["CET4","考研","雅思"]
senses[].pos  → n. v. adj. adv. prep. conj. pron. art.
senses[].definition_cn  → 必填
breakdown[].form → 必须与 morphemes.jsonl 的 form 完全一致（注意连字符）
breakdown[].note → 该词素在这个词里的具体含义（差异化内容，很值得写）
gloss         → 一句话串讲，本站最有价值的内容字段
```
